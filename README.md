# tenset-stick-figure-illustrator

极简火柴人概念插画 Skill：将中文观点、学习概念和文章内容，转成白底黑线、生活场景隐喻和少量文字组成的解释性配图。

## 能做什么

- 根据一句观点或一段文章设计具体的视觉隐喻，保留原文的条件与关系。
- 输出配图方案、绘图提示词，或配合当前环境可用的图像工具生成、修改图片。
- 统一自然细线、简笔火柴人、大量留白和可选红色关系标注，检查文字与概念表达。

## 使用

将整个仓库放入 Codex 的 skills 目录，文件夹名称保留为 tenset-stick-figure-illustrator。实际生成位图需要当前环境提供 imagegen 技能与内置图像生成工具；只输出方案或提示词不需要生成工具。

```text
使用 $tenset-stick-figure-illustrator，
为“频繁切换任务，会让人反复找回上下文”生成一张配图。
参考样本的白底黑线和火柴人画风，文字尽量少。
```

也可以指定“只给配图方案”或“只给提示词”。默认不将图片写回文章，不上传或发布文章。

## 文件

- [SKILL.md](SKILL.md)：触发范围、画风、配图方法、生成检查与交付规则。
- [agents/openai.yaml](agents/openai.yaml)：界面名称与默认调用提示词。
- [参考样本索引](references/参考样本索引.md)：11 张参考图的用途和适用边界。
- [构图与提示词](references/构图与提示词.md)：关系构图、提示词骨架与迁移示例。

## 维护

在本仓库修改 Skill 及参考资料，检查文档链接与 YAML 后，再同步到本机已安装的 Skill 目录。新增样本应使用中文名称并编号，并更新索引；根据实际使用反馈做小范围修订，避免把单张图的要求固化为全局风格。

当前版本已完成 Skill 结构和本地资源检查，尚未通过实际生成图片验证风格贴合度。
