# 构图与提示词

## 先选择表达关系

| 内容关系 | 可考虑的构图 | 成立条件与易错处 |
|---|---|---|
| 当前状态与目标有差距 | 左右两个状态，中间留出可见距离 | 跨越不表示瞬间完成；红箭头只说明关系 |
| 过程有反复或阻碍 | 一条路径配少量障碍或分岔 | 不能把所有迭代都画成负面弯路 |
| 外部支持改变行动条件 | 人物使用一件与问题直接相关的道具 | 说明支持在哪一步有用，避免道具等于万能解法 |
| 行为或情绪差异 | 同一情境的不同姿态，或两人对话 | 用动作和话语呈现，不把姿态当人格诊断 |
| 信息组织差异 | 同类对象、相近尺度的左右对照 | 除组织方式外尽量保持对比条件相近 |
| 无形成本或资源限制 | 具象化的负重、空间、取用过程 | 必须说明隐喻对应项，不能伪造量化刻度 |

不要总用悬崖、道路和向上跑步。隐喻合适与否取决于它是否保留了原文关系，单纯“像一张励志图”不算解释成功。

## 单图提示词骨架

按任务删减字段，不向用户展示内部推导，也不要求用户填完所有项目才开始。

```text
用途：中文文章正文中的极简手绘概念插画。
要解释的观点：[一句话，明确关系而非宽泛主题]
场景：[一个具体的生活场景，说明各元素分别对应什么]
主体与动作：[人物数量、姿势、关键道具；不需要人物时省略]
构图与关系：[前后、左右或其他空间关系；箭头仅在有意义时使用]
图中文字（逐字准确）：[少量标签或短对白；无需文字时明确无文字]
比例：[按内容选择，未指定时横向约16:9]

白色背景，黑色自然细线，线宽基本一致，略有手绘弯曲和断笔。
人物采用圆形无五官头部和单线身体四肢，动作清楚；道具使用简笔轮廓。
一幅图集中解释一个观点，大量留白，画面简洁但关系完整。
文字清楚，使用宋体或楷体气质，不用潦草字体。
[需要时：仅用少量红色箭头或关系线强调指定位置。]
不添加大标题、渐变、阴影、彩色填块、复杂服饰或无关装饰。
若有参考图，仅学习其线条、造型和解释性构图；按本次主题重新设计主体和文字。
```

## 迁移示例：采用新内容，不照抄样本

这些是设计示例，不是已经生成或通过验收的图片。

### A：任务切换使人反复找回上下文

- 场景：一个火柴人在两张工作桌之间来回，每张桌上各有一本翻开的笔记；人物重新坐下时沿着书签寻找上次的位置。
- 映射：两张桌对应两项任务，找书签对应恢复上下文；避免画成两个人竞争、两项任务同时完成或数倍耗时的量化结论。
- 标签：两张桌分别标“任务 A”“任务 B”，书签旁仅标“做到哪了？”。箭头只用于表示切换，不额外加红色成功标志。

### B：搜索与目录提供不同的找信息方式

- 场景：左右各一个相同大小的资料架，左边火柴人查看分类索引，右边火柴人用带关键词的小卡片寻找对应资料。
- 映射：呈现导航方式的差异，保持资料数量与人物状态相近；不把任一侧画成失败者，也不声称搜索必然更快。
- 标签：“按分类找”“按关键词找”，无需长段对话；物件可适度细化，人物保持简笔。

### C：只要提示词，不生成图片

输入“为‘知识需要整理才能方便调用’写一条此风格的绘图提示词”，应交付具体的场景、关系和精确文字，不调用生成工具、不复制原衣柜样本。

## 识别边界

- “画服务部署架构，精确标出容器、端口与依赖”：采用架构图工作流；火柴人场景难以承担精确依赖表达，不强行套风格。
- “把这张火柴人图的红箭头移到右边”：只编辑箭头，保留其他元素和文字，不重写整个场景。
- “画一个学习过程，别出现人物”：可以用对象、路径与状态表达，遵从本次要求。
- “配图里逐字保留这段长文字”：保留原文，选择更合适的画幅、分图或排布；若明显无法兼顾可读性，说明具体冲突再询问关键取舍，不擅自删字。

## 成品检查

看图时回答以下问题：主要关系是否成立，是否把可选条件画成必然结果，人物动作和道具是否可辨，中文字是否准确且完整，是否出现多余彩色或商业插画质感，缩小后关键标签是否仍可读。

若风格偏离，针对线条、造型或背景具体修正；若概念映射有误，先重做场景关系。不要仅加一句“更像参考图”，也不在未看图时声称通过视觉检查。
